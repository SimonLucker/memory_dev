The system

Typeface and sizes

Display 36
Headline 22
Body 16
Label 13

Geist, weights 400/500/600. These four sizes only. Nothing below 13. A crowded screen loses elements, not font size.

Colors

App background
Opened memory
Cortex
Profile
Data heat scale

No accent color. The heat scale colors data only: timeline, gauge, person dots. The purple theme is replaced by these.

Navigation

VaultCaptureCards

Three horizontal panes. Swipe, or tap the dots at the top. The app opens in Capture. Profile opens from the avatar. No dropdown menus.

View names: Capture (was Memorialize), Vault, Cortex, Cards, Profile.

Thread history

Everything sent stays in the thread. A saved memory becomes a card inside it. Older months load from cache as you scroll up, under sticky month headers.

Today the chat empties after a save. That changes in pass one.

Photos and icons

Photos straight, full width, rounded corners. Never tilted, never half screen. No floating background particles.

Icons are 1.5px line drawings on a 24px grid, ink colored. No emoji in the interface.

Voice notes

Holding the mic records a voice note. It lands in the thread as a playable message: waveform, duration, play button.

Transcription runs in the background and makes the note searchable. It never replaces the audio.

Build order

1 · The reset

  • Dawn palette replaces purple
  • Type scale 36/22/16/13
  • Three panes + dots, dropdown removed
  • Line icons replace emoji
  • Photos straight, full width
  • Background dust removed
  • Names: Capture, Vault, Cortex, Cards
  • Voice notes playable, transcript silent
  • The thread keeps its history

2 · The mechanics

  • Forming bar + Save now, card stays in thread
  • Infinite scroll with cached months
  • Memory detail: media grid, Maps row, Spotify row, labeled sections, Add, Tag people
  • Long press menus
  • Vault rows to four elements
  • Cortex: 3D nodes, photo nodes up close, search, gradient heat pill, three zoom levels

3 · The magic

  • Moment mode + auto suggest
  • The proactive keeper
  • Slideshow
  • On this day
  • Profile: counts, top people, gauge, AI Insights
  • Cards pane + first woven card
  • Widget + share sheet capture
